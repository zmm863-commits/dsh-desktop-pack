## 四、常见问题

**Q：这些插件可以关掉吗？**
可以。在「设置 → 插件」里单独启用/停用任意插件；泡泡猫主题也有总开关，关掉即完全还原原生界面。

**Q：会收集我的数据吗？**
不会。所有配置与数据都保存在本机 `%APPDATA%\PaopaocatDSH`，服务只监听 `127.0.0.1`，不对外开放。

**Q：需要自己装 Node.js 吗？**
不需要。安装包内置 Node.js 与 Git，无需任何前置环境。

**Q：首次启动要做什么？**
只需填入自己的 API Key（DeepSeek 官方或任意 OpenAI 兼容接口），之后直接使用。

**Q：怎么自己加插件？**
用内置的 🛒 插件市场，或在命令行执行 `dsh plugin --profile web add <插件名>`。
