# 泡泡猫 DSH 桌面版 v3.1.15 · 发布说明

> 本文件内容与 `作品-payload.json` 的详细介绍一致，后台可整段粘贴。

## 它是什么

**泡泡猫 DSH 桌面版**把 DSH（DeepSeek Harness）整套 AI 工作台封装成开箱即用的桌面应用 —— 不需要 Node.js、不需要命令行、不需要配环境变量。

- **内置运行时** — 自带 Node 22 与全部依赖，装完直接能跑
- **预装 18 个插件** — 🎬 泡泡猫影视工具（含 Oh Story 创作套件）· 🐱 泡泡猫新主题 · 🎲 骰子大作战 · 📝 即时便签 · 🧠 长期记忆库 · 👁️ 视觉路由 · 🔁 LLM 容错 · 🤖 领域专家团 · 📊 GenUI · 📚 Oh Story · 🧩 技能管理器 · 💬 IM 接入 · 📦 归档管理 · 🛒 插件市场 · 📋 插件排行 · ⏰ 定时自动化
- **多模型路由** — 一个界面里切换各家模型；会话、密钥、文件全部落在本机
- **本次版本 v3.1.15** — 基于 DSH 0.1.7-rc.2 重新打包，内置长期记忆库（Mnemon 全套 17 个包）

## 🪟 Windows 安装

1. 下载「**Windows 10/11 (64 位) 安装版**」
2. 双击运行，按向导完成安装
3. 首次启动会引导你填入模型 API Key
4. 若出现 SmartScreen 蓝色提示，点「更多信息 → 仍要运行」

| 项目 | 位置 |
|---|---|
| 安装目录 | `%LOCALAPPDATA%\Programs\PaopaocatDSH` |
| 数据目录 | `%APPDATA%\PaopaocatDSH` |
| 启动方式 | 桌面快捷方式 / 开始菜单 |
| 系统要求 | Windows 10 1809+ / 11，64 位 |

---

## 🍎 macOS 安装（仅脚本安装一种方式）

1. 下载「**macOS 通用版（脚本安装）**」并解压
2. 在解压出的文件夹里**双击「安装泡泡猫DSH.command」**
3. 若提示「无法打开，因为来自身份不明的开发者」：在该文件上**右键 → 打开**，再点一次「打开」
4. 之后全自动：解压 → 安装到「应用程序」→ 清除安全拦截 → 启动

| 项目 | 说明 |
|---|---|
| 系统要求 | macOS 11.0 或更高 |
| 芯片支持 | Intel / Apple Silicon 通用（双架构） |
| 数据目录 | `~/Library/Application Support/PaopaocatDSH` |
| 前置依赖 | 无 —— 不需要 Xcode、不需要命令行、不需要 Node.js |

> 下载包里同时含有安装脚本与安装包，脚本会自动寻找同目录下的 `PaopaocatDSH-macOS-*.zip`；若你单独把脚本拿出去，双击后会弹出文件选择框让你手动选中安装包。

## 首次使用

1. 启动后会自动打开浏览器界面（本地 `127.0.0.1`，不对外网开放）
2. 按引导填入模型 API Key（支持 DeepSeek 等）
3. 侧边栏即为预装的插件入口

## 常见问题

**装完打不开？** 看启动器窗口输出的日志（Windows 在 `%APPDATA%\PaopaocatDSH\launcher.log`）。
**需要联网吗？** 安装过程不需要；使用模型时需要。
**升级会丢数据吗？** 不会。覆盖安装只更新程序文件，会话记录与 API Key 都会保留。
**体积为什么这么大？** 安装包内含完整运行时与全部插件依赖，所以无需另装任何东西。
