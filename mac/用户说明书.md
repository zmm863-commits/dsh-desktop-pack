# 泡泡猫 DSH 桌面版 · 用户说明书（macOS）

> 版本 3.1.15 ｜ 支持 Intel 与 Apple 芯片 ｜ 需 macOS 11.0 或更高

---

## 一、这是什么

**泡泡猫 DSH** 是一个装在你自己电脑上的 AI 助手工作台。它把 DeepSeek Harness（DSH）连同 18 个插件一起打包好，双击就能用，**不需要安装 Node.js、Python、Git 等任何额外软件**。

装好之后，你会得到一个本地运行的 AI 对话界面，可以：

- 和 AI 聊天、让它写代码、改文件、跑命令
- 📖 **Oh Story** — 小说创作（长篇/短篇/拆文/封面）
- 🎬 **影视工具** — 文生图、图生视频、剧本转分镜
- 🎲 **骰子大作战** — 几款小游戏
- 📎 **文件上传、主题皮肤**等

## 二、安装前的准备

**唯一要求**：macOS 11.0（Big Sur）或更高版本。

> 不确定自己的系统版本？点左上角  → 「关于本机」查看。

### ⚠️ 重要：请先更新 Safari

新版界面**依赖较新的浏览器内核**。如果你的 **Safari 低于 16.4**，网页会一片空白。

**检查方法**（打开「终端」，粘贴执行）：

```bash
defaults read /Applications/Safari.app/Contents/Info.plist CFBundleShortVersionString
```

**如果结果低于 16.4**，请先更新：

```bash
softwareupdate --list
```

看列表里有没有 `Safari`，有就装（或打开「系统偏好设置 → 软件更新」）。

## 三、安装

### 方式一：一键脚本（推荐）

1. 下载 `安装泡泡猫DSH.command`
2. **右键点击 → 打开**（不要直接双击）
3. 如果提示「无法打开，因为来自身份不明的开发者」，去 **系统偏好设置 → 安全性与隐私 → 通用**，点「仍要打开」
4. 脚本会自动解压、安装到 `/Applications`、清理隔离标记
5. 装完会问你要不要立即启动，选「是」

### 方式二：手动安装

1. 下载 `PaopaocatDSH-macOS-v3.1.15-universal.zip`（约 573.5MB）
2. **双击解压**（用「归档实用工具」，会正确保留文件权限）
3. 把解压出来的 `PaopaocatDSH.app` 拖到「应用程序」文件夹
4. 打开「终端」，粘贴执行（清除下载隔离标记）：

```bash
xattr -cr /Applications/PaopaocatDSH.app
```

5. 双击 `PaopaocatDSH.app` 启动

## 四、第一次启动

双击应用后，会**弹出一个终端窗口**，显示启动进度：

```
[1/5] 检查数据目录...
[2/5] 检查 API Key...
[3/5] 校验配置文件...
[4/5] 准备运行环境（内置 Node / Python、系统 Git）...
[5/5] 正在启动服务...
```

**首次启动约需 10~30 秒**，请耐心等待。启动完成后会自动打开浏览器。

> ⚠️ **这个终端窗口不要关闭** —— 关掉它 DSH 就停止运行了。要退出时再关。

### 浏览器选择

启动器会**自动优先使用 Chrome / Edge**（如果装了）。若都没装，会用系统默认浏览器。

- **如果界面一片空白** → 多半是 Safari 版本太旧，见第二节
- **推荐**：装个 Chrome，体验最稳

### 记下访问地址

终端里会打印类似这样的一行：

```
界面地址：http://127.0.0.1:3080/?token=xxxxxxxxxxxx
```

**第一次必须用这个带 token 的完整地址访问**（启动器会自动帮你打开）。

**成功访问一次之后**，浏览器就记住了身份，以后**直接访问 `http://127.0.0.1:3080` 就行**（建议存成书签）。

> 💡 **不要收藏带 token 的地址** —— token 每次启动都会变，收藏了会失效白屏。收藏**不带 token** 的那个。

## 五、配置 API Key

首次使用需要填 AI 服务的 API Key。

1. DSH 界面里打开**设置**
2. 填入你的 API Key（支持 DeepSeek、Agnes、Qwen、豆包、MiniMax、Ollama 等）
3. 保存

**Key 存在本地**（`~/Library/Application Support/PaopaocatDSH/.credentials.yaml`），不会上传到任何地方。

**去哪领免费 Key**：
- DeepSeek：https://platform.deepseek.com
- Agnes：https://platform.agnes-ai.cn
- Ollama：本地运行，无需 Key

## 六、日常使用

### 启动

双击 `PaopaocatDSH.app`，等浏览器自动打开。

### 停止

**关闭那个终端窗口**即可（或在终端里按 `Ctrl + C`）。

### 数据存放位置

```
~/Library/Application Support/PaopaocatDSH/
├── settings.yaml        # 配置
├── .credentials.yaml    # API Key（权限 600，仅你可读）
├── profiles/            # 插件与运行环境
├── sessions/            # 对话记录
├── launcher.log         # 启动日志（排查问题用）
└── logs/                # 运行日志
```

### 升级版本

重新下载新版安装包，**按同样步骤安装一遍**即可 —— 会自动覆盖程序文件，**你的配置、Key、对话记录都不会丢**。

## 七、常见问题

### 网页一片空白

**最常见原因：Safari 版本太旧**（低于 16.4）。

```bash
# 检查版本
defaults read /Applications/Safari.app/Contents/Info.plist CFBundleShortVersionString
```

- **低于 16.4** → 更新 Safari（见第二节）
- **已经是 16.6.1 还白屏** → 按 `Option + Command + I` 打开控制台，把红色报错发给开发者

### 左下角一直显示"自动重连"

说明浏览器和后端的长连接没建立起来。

1. 确认那个**终端窗口还开着**（关了就停了）
2. 检查地址是否带 `?token=`
3. 按 `F12` 看 Console 报错

### 提示"本轮运行失败"

多半是缺了某个组件。检查启动日志：

```bash
cat ~/Library/Application\ Support/PaopaocatDSH/launcher.log
```

### 要求我下载 python3 / 开发者工具

正常情况**不应该出现**（包里已内置 Python）。

如果出现了，说明启动方式不对 —— 请**通过双击 `PaopaocatDSH.app` 启动**，而不是在终端里直接跑命令。

### 提示"无法打开，因为 Apple 无法检查"

这是未签名应用的标准提示。

**解决**：右键点击应用 → 「打开」→ 在弹窗里点「打开」。
或者执行：`xattr -cr /Applications/PaopaocatDSH.app`

### 想看启动日志

```bash
cat ~/Library/Application\ Support/PaopaocatDSH/launcher.log
```

## 八、卸载

```bash
# 1. 停止运行（关闭终端窗口），然后删除程序
sudo rm -rf /Applications/PaopaocatDSH.app

# 2. 删除用户数据（可选，会丢失配置和对话记录）
rm -rf ~/Library/Application\ Support/PaopaocatDSH
```

## 九、给技术用户的补充

- **最低系统**：macOS 11.0（由 Node.js 22 与原生模块决定）
- **包内含**：Node.js 22.23.2、便携 Python 3.11、18 个插件，双架构通用
- **端口**：3080（可用 `lsof -nP -iTCP:3080` 查看占用）
- **日志**：`~/Library/Application Support/PaopaocatDSH/launcher.log`
- **停止**：`pkill -f "PaopaocatDSH.app/Contents/Resources/runtime/node"`

更深入的技术细节（架构、兼容性补丁、构建流程）见同目录的 **`技术文档.md`**。
