泡泡猫 DSH · 桌面版
========================================

【这是什么】
把 DeepSeek Harness（DSH）完整打包成的 Windows 桌面应用：
内置 Node 运行时和全部 14 个插件，安装即用，无需命令行。

【安装】
1. 双击 泡泡猫DSH桌面版-Setup-x64.exe
2. 按提示选择安装位置（默认装到当前用户目录，不需要管理员权限）
3. 安装完成后桌面会出现「泡泡猫 DSH」图标

【首次启动】
1. 双击桌面「泡泡猫 DSH」图标
2. 首次运行会弹窗要求填入 DeepSeek API Key：
   - 没有 Key？弹窗里有直达链接，到 https://platform.deepseek.com 注册并创建
   - Key 只保存在你自己电脑的 %APPDATA%\PaopaocatDSH\.env，不会上传
3. 点确定后服务自动启动，浏览器自动打开 http://127.0.0.1:3080

【日常使用】
- 点桌面图标 = 启动服务并打开界面（若已在运行则直接打开网页）
- 关闭黑色控制台窗口 = 停止 DSH
- 默认模型 deepseek-chat；要深度推理可在设置里切到 deepseek-reasoner

【数据都在哪里】
%APPDATA%\PaopaocatDSH\
  ├─ profiles\web\     全部插件
  ├─ sessions\         会话记录
  ├─ settings.yaml     配置（可手动加其他模型提供者）
  └─ .env              API Key
卸载程序默认保留该目录；确认不再需要时可选删除。

【已知限制】
- bash 工具已内置便携版 Git（v1.1.0 起），开箱即用，无需另装 Git Bash
- IM 连接插件的无头浏览器会自动使用 Windows 自带的 Edge；若被精简掉，
  安装 Chrome 即可
- 视觉类工具（识图等）需要视觉模型：DeepSeek 官方 API 目前只有文本模型，
  如需识图请在 设置 中添加任意一家视觉模型提供者（如硅基流动、LongCat）
  并填入对应 Key
- 默认端口 3080，被占用时请先关闭占用它的程序
- 首次安装运行时 Windows SmartScreen 可能提示未签名，点「仍要运行」即可；
  彻底消除提示需要代码签名证书（付费）

【常见问题】
Q: 双击桌面图标没反应？
A: v1.2.0 起每次启动都会写日志 %APPDATA%\PaopaocatDSH\launcher.log，
   打开它即可看到卡在哪一步；也可以直接运行安装目录下
   launcher\dsh-launcher.bat（黑窗口版）查看实时报错。
Q: 双击图标后一闪而过？
A: 控制台里若有报错请截图反馈。最常见原因是杀毒软件拦截 node.exe，加白名单即可。
Q: 浏览器没自动打开？
A: 手动访问 http://127.0.0.1:3080
Q: 想换 API Key？
A: 删除 %APPDATA%\PaopaocatDSH\.env 后重新双击图标，会再次弹出输入窗。
